# Code scripts for SickMix outbreak modeling simulations 

1. 'SickMix_Aim1_SIR_Models.R' contains code for outbreak simulations using a behavior-dynamic and a behavior-naive model. 
2. 'SickMix_Aim1_Isolation_Intervention_Simulations.R' contains code for simulating age-targeted isolation-based interventions. 
3. 'SickMix_Aim1_Vaccination_Simulations.R' contains code for simulating age-targeted vaccination interventions.
