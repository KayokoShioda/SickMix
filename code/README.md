# Code scripts for SickMix outbreak modeling simulations 

'SickMix_Aim1_SIR_Models.R' contains code for outbreak simulations using a behavior-dynamic and a behavior-naive model. 

'SickMix_Aim1_Isolation_Intervention_Simulations.R' contains code for simulating age-targeted isolation-based interventions. 

'SickMix_Aim1_Vaccination_Simulations.R' contains code for simulating age-targeted vaccination interventions.
