# **Contact Matrices - Cases**

The contact calculation process is described here. 

Each file contains an age-structured matrix corresponding to weighted mean contacts among acute gastroenteritis and acute respiratory infection cases 
for three survey time points: index survey (most sick day), 1-week follow-up survey, 2-week follow-up survey. 

The row names represent the respondent group (ill individuals), and the column names represent the contact group. Respondent ages are grouped into 7 age groups: 
<1 year, 1-4 years, 5-17 years, 18-29 years, 30-44 years, 45-64 years, 65+ years). 
Contact age groups are grouped into 6 age group: <5 years, 5-17 years, 18-29 years, 30-44 years, 45-64 years, 65+ years. 

The name of the files follow the same naming pattern: ‘cases_survey_matrix.xlsx’, where survey corresponds to the survey time point. 

Additionally, the file named ‘cases_index_home_matrix.xlsx’ corresponds to the mean reported contacts between cases and their household members at home 
at the index survey.
